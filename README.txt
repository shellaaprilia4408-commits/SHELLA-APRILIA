PORTOFOLIO SHELLA APRILIA

Isi folder:
- index.html  : struktur halaman website
- style.css   : tampilan, warna, layout, dan responsive design
- script.js   : menu mobile, animasi saat scroll, dan tahun otomatis

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder "portofolio_shella" di Visual Studio Code.
3. Jika memakai Live Server, klik kanan index.html lalu pilih "Open with Live Server".
   Atau klik dua kali index.html untuk membukanya langsung di browser.

Catatan:
- Website menggunakan Google Fonts sehingga font khusus memerlukan koneksi internet.
- Bagian karya saat ini berupa kategori/ilustrasi dekoratif, bukan dokumentasi karya asli.
  Ganti ilustrasi tersebut dengan foto atau screenshot karya milikmu jika sudah siap.
- Tautan Instagram, LinkedIn, dan email sudah dipasang.
- Periksa kembali informasi dan tautan sebelum website dipublikasikan.
